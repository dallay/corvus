# Changelog

Corvus no longer maintains this file as the canonical stable release ledger.

- For canonical release notes and attached assets, see the [GitHub Releases for dallay/corvus](https://github.com/dallay/corvus/releases).
- Stable merges to `main` are orchestrated by `release-please`, which owns the canonical `vX.Y.Z` tag, GitHub Release, and release notes.
- Stable artifact publication starts from `release.published`, and `.github/workflows/_publish.yml` only attaches assets to the existing GitHub Release.
- Snapshot runs do not update this file and do not create stable GitHub Releases.
