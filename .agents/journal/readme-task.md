# Learning: README Documentation Best Practices

- A comprehensive README should include: Project Title, Punchy Description, TOC, Features, Tech Stack, Project Structure, Getting Started (Prerequisites, Installation, Usage), Development (Commands, Env), Documentation, Contributing, and License.
- In monorepos, a clear explanation of the directory structure is crucial for onboarding.
- Standardizing commands using a `Makefile` or similar tool simplifies the user experience.
- Automated formatting tools like `spotlessCheck` are essential to maintain documentation quality.
