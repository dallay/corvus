# Bienvenido a Corvus

Corvus es un sistema potente y modular diseñado para construir aplicaciones escalables. Esta documentación te ayudará a entender, instalar y usar sus capacidades principales de manera efectiva.

## Características Clave

- **Diseño Modular:** Fácilmente configurable y escalable.
- **Seguridad ante todo:** Construido con valores predeterminados seguros y buenas prácticas.
- **Multiplataforma:** Soporta configuraciones para Android, iOS, Escritorio y Web.

## Empezando

Para comenzar con el Corvus Agent Runtime, consulta la guía de [Arquitectura](/es/clients/agent-runtime/architecture/).

## Componentes

Corvus consta de varios componentes clave:

- **Agent Runtime:** Un sidecar de Rust de alto rendimiento.
- **Compose App:** Componentes de UI compartidos para la gestión.
- **Web Dashboard:** Una interfaz central para monitoreo y control.
