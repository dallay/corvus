# Proveedor Ollama (Local)

Ollama permite ejecutar modelos de código abierto de forma local.

## Configuración

Por defecto, Corvus espera que Ollama se esté ejecutando en `http://localhost:11434`.

```bash
export OLLAMA_HOST=http://localhost:11434
```

## Modelos compatibles

- llama3
- mistral
- phi3
