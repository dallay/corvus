# Proveedor OpenAI

OpenAI es uno de los proveedores de IA más potentes y utilizados.

## Configuración

Para usar OpenAI con Corvus, configure su clave API en el entorno:

```bash
export OPENAI_API_KEY=sk-...
```

## Modelos Compatibles

- gpt-4o
- gpt-4-turbo
- gpt-3.5-turbo
