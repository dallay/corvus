Corvus soporta una amplia gama de providers de IA, incluyendo tanto opciones basadas en la nube como locales. Puedes configurar tu provider preferido durante el proceso inicial de configuración o editando tu archivo `config.toml`.

## Autenticación Avanzada

Algunos providers soportan métodos de autenticación avanzados más allá de las simples claves de API:

### Autenticación OAuth y CLI

- **Google Gemini**: Corvus puede reutilizar automáticamente las credenciales de la CLI de Gemini. Si has ejecutado `gemini` y te has autenticado, Corvus encontrará tus tokens OAuth en `~/.gemini/oauth_creds.json`.
- **OpenAI Codex**: Utiliza un flujo basado en OAuth para la autenticación.
- **GitHub Copilot**: Reutiliza tu autenticación de la CLI de GitHub o los tokens proporcionados por el entorno.

### Tokens de Configuración (Setup Tokens)

Para **Anthropic**, puedes usar un `ANTHROPIC_OAUTH_TOKEN` (token de configuración) como alternativa a una clave de API estándar.

## Providers Regionales y Especializados

Corvus también soporta varios providers regionales y especializados, particularmente para el mercado chino:

- **Moonshot (Kimi)**: `moonshot`, `moonshot-intl` (`MOONSHOT_API_KEY`)
- **GLM (Zhipu)**: `glm`, `glm-cn` (`GLM_API_KEY`)
- **MiniMax**: `minimax`, `minimax-cn` (`MINIMAX_API_KEY`)
- **Qwen (DashScope)**: `qwen`, `qwen-intl`, `qwen-us` (`DASHSCOPE_API_KEY`)
- **Qianfan (Baidu)**: `qianfan` (`QIANFAN_API_KEY`)
- **Z.AI**: `zai`, `zai-cn` (`ZAI_API_KEY`)

## Endpoints Personalizados

Si tienes una API alojada por ti mismo o compatible con OpenAI/Anthropic, puedes usar una cadena de provider personalizada:

- **Compatible con OpenAI**: Usa `custom:<URL>` como el nombre del provider.
- **Compatible con Anthropic**: Usa `anthropic-custom:<URL>` como el nombre del provider.

Ejemplo:
```bash
corvus onboard --provider "custom:http://localhost:1234/v1" --api-key "tu-clave"
```

## Resolución de Credenciales

Corvus resuelve las credenciales en el siguiente orden:

1. `api_key` proporcionada explícitamente en `config.toml`.
2. Variable de entorno específica del provider (por ejemplo, `ANTHROPIC_API_KEY`).
3. Variables de entorno genéricas de respaldo (`CORVUS_API_KEY` o `API_KEY`).
