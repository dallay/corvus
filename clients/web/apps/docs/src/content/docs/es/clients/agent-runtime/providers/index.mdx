# Proveedores de IA

Corvus Agent Runtime admite una amplia gama de proveedores de IA. Puede configurarlos utilizando variables de entorno o el archivo de configuración.

## Configuración Común

La mayoría de los proveedores requieren una clave API. Puede configurarla globalmente usando la variable de entorno `API_KEY`, o usar variables específicas del proveedor como `OPENAI_API_KEY`.
