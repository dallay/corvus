# OpenAI Provider

OpenAI is one of the most powerful and widely used AI providers.

## Configuration

To use OpenAI with Corvus, set your API key in the environment:

```bash
export OPENAI_API_KEY=sk-...
```

## Supported Models

- gpt-4o
- gpt-4o-mini
- gpt-4-turbo-2024-04-09
