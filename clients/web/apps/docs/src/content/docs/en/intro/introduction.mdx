# Welcome to Corvus

Corvus is a powerful, modular system designed for building scalable applications. This documentation will help you understand, install, and use its core capabilities effectively.

## Key Features

- **Modular Design:** Easily configurable and scalable.
- **Security-First Approach:** Built with secure defaults and best practices.
- **Cross-Platform:** Supports Android, iOS, Desktop, and Web setups.

## Getting Started

To get started with the Corvus Agent Runtime, check out the [Architecture](/en/clients/agent-runtime/architecture/) guide.

## Components

Corvus consists of several key components:

- **Agent Runtime:** A high-performance Rust sidecar.
- **Compose App:** Shared UI components for management.
- **Web Dashboard:** A central interface for monitoring and control.
