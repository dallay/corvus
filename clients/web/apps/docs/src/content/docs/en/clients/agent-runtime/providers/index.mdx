# AI Providers

The Corvus Agent Runtime supports a wide range of AI providers. You can configure them using environment variables or the configuration file.

## Common Configuration

Most providers require an API key. You can set it globally using the `API_KEY` or `CORVUS_API_KEY` environment variable, or use provider-specific variables like `OPENAI_API_KEY`.
